## 🚀 Getting Started

### Run locally

1. **Clone the repository**
```bash
   git clone https://github.com/your-username/your-repo-name.git
```
2. **Open the folder**
```bash
   cd your-repo-name
```
3. **Open `index.html`** in your browser (double-click it, or use the Live Server extension in VS Code).

No installation or build step is needed.

### Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and the `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://your-username.github.io/your-repo-name/`.

## 🎨 Customization

- **Colors:** The theme uses `#8876d0` (purple accent) and `#17233c` (dark navy). Change these in `style.css`.
- **Skill levels:** Edit the width of `.html`, `.css`, `.cpp`, and `.python` in `style.css` to update the progress bars.
- **Projects:** Duplicate a `.project-card` block in `index.html` to add a new project.
- **Images:** Replace the image files and update the `src` paths in `index.html`.
